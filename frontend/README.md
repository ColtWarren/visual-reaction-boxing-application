# Frontend

React + TypeScript Progressive Web App.
Initialized with Vite in Step 2.

## Planned Stack

**Core (installed in Step 2):**
- React 18+
- TypeScript
- Vite
- Tailwind CSS (utility-first styling)
- shadcn/ui (component primitives)
- React Router v6
- Lucide icons
- vite-plugin-pwa

**Tooling (installed in Step 2):**
- ESLint
- Prettier

**Candidate libraries (added when needed, not at init):**
- Framer Motion — for polish-phase micro-interactions

## Node Version

This folder uses **Node 20 LTS**, pinned in `.nvmrc`. The file contains
only the version number (`20`) — no comments, because some version
managers parse strictly.

Activate with your version manager:

- nvm: `nvm use`
- fnm: `fnm use`
- volta: auto-detected
- asdf: `asdf install nodejs $(cat .nvmrc) && asdf local nodejs $(cat .nvmrc)`
